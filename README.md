# Gift Collector

A mod for [Dungeon Rampage Haxe](https://github.com/Tutez64/Dungeon-Rampage-Haxe).

## What it does

**Gift Collector** automatically collects and accepts selected gifts when you enter the town, provided there is enough inventory space.

The mod checks your inventory and only accepts gifts for items that are not already at their inventory limit. This helps prevent unnecessary gifts from being accepted when your inventory is full.

It also removes the gift notification from the town screen, keeping the interface clean.

<!-- drh:show -->

## Features

- Automatically detects available gifts.
- Automatically accepts selected gifts during the loading screen when sufficient inventory space is available.
- Checks inventory limits before accepting gifts.
- Optionally hides the gift notification from the town screen.
- Avoids accepting gifts when the corresponding inventory is full.

<!-- /drh:show -->

## How to use

1. Install and enable **Gift Collector** in the DRH Launcher.
2. Start the game.
3. Enter the town.
4. The mod automatically checks your inventory and available gifts.
5. Eligible gifts are accepted automatically.

No additional configuration or manual interaction is required.


## Installation

Install the mod through the DRH Launcher.

For information about creating and installing mods, see the [Making a mod guide](https://github.com/Tutez64/Dungeon-Rampage-Haxe/blob/master/docs/making-a-mod.md).
